feat: expressive reactive owl + AI/ML course track

The owl now reacts to how the student is actually doing, and the catalog
covers artificial intelligence end to end.

The owl
Mood is separate from status on purpose. Status is the lifecycle (idle /
thinking / speaking); mood is the personality. An owl that is *speaking* can
be excited, curious, or supportive - folding those into one enum would
multiply into a mess. The expressive work is in the geometry, not the colour:
brows, closed happy arcs, an open supportive palm, and blush/sparkles that
appear only on warm moods, because a permanent sparkle is just noise.

- react() maps an outcome to a mood and speaks a matching line, alternating
  between two phrasings so it never repeats itself
- "close" and "wrong" are distinct reactions - being nearly right is a
  different moment from missing entirely, and one "wrong" face would make the
  owl look like it isn't paying attention
- celebration plays a real hop with squash-and-stretch, plus sparkles
- a gentle nod when the answer is wrong, rather than a shrug
- reactions relax to neutral after 4.2s so the owl never looks stuck
- breathing on the body, and the blink is randomised per render so it never
  falls into a metronome the student can predict

Course catalog
Five AI/ML tracks, 30 modules: machine learning fundamentals, neural networks
(perceptron -> backpropagation -> CNN/RNN), transformers and LLMs (attention,
tokenization, context windows, hallucination), prompting and RAG, and AI in
practice (bias, drift, cost, safety, privacy). The seeder keys on title, so
these appear on existing databases too.

Two bugs the tests caught
- The mood class and .owl-visual are set on the same element, so the hop was
  written as a descendant selector and silently never matched. Asserting the
  computed animation-name is what found it.
- react() originally set the owl's status directly, which would have left it
  stuck in "speaking" with no timer to bring it back. main.ts owns the
  lifecycle, so react() only touches mood now.
